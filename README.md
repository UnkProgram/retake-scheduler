# Retake Scheduler

Веб-сервис автоматического составления расписания пересдач и защит.

Учебный проект по дисциплине «Основы технологии командной разработки программного обеспечения».

## Возможности (MVP)

- импорт и ввод студентов, преподавателей, аудиторий;
- автоматическое составление расписания без накладок;
- просмотр по преподавателю, аудитории, студенту;
- ручная корректировка с проверкой конфликтов;
- экспорт в CSV и XLSX.

## Стек

Python 3.12, FastAPI, SQLAlchemy, SQLite, Jinja2, pytest, Ruff, GitHub Actions, Redmine, Docker.
